# 网络、流量与隐私边界

## 数据在哪里

应用将设置、来源列表、历史和运行记录保存在本机。CSV/全状态导出由用户通过 Android 系统文档选择器选择目的地；应用没有为这些导出自动上传数据的功能。但若选择云盘文档提供方，该提供方可能同步文件，具体由用户和提供方设置决定。

导出可包含 IP、URL、网络描述、时间与测速结果。对外反馈前请先脱敏，不要分享完整私人备份。

## 哪些操作联网

测速会连接所选候选 IP。**“从 GitHub 更新”即使关闭自定义列表镜像开关，仍会依次尝试内置第三方镜像，最后才尝试 raw.githubusercontent.com；成功后即停止后续尝试。** 启用自定义镜像只是将其加入优先尝试位置，不会关闭内置镜像。当前内置镜像主机为 `ghps.cc`、`gh-proxy.com`、`ghfast.top`、`ghproxy.vip`、`ghproxy.cc`、`ghproxy.net`、`ghproxy.click`。它们是独立第三方服务，可能记录请求、改变返回内容或不可用；不要将关闭自定义镜像理解为“仅访问 GitHub 官方”。

“从 Cloudflare 更新”另走 `www.cloudflare.com/ips-v4` 或 `www.cloudflare.com/ips-v6` 官方地址。若不希望接触内置镜像，请避免使用 GitHub 更新入口，可选 Cloudflare 更新或本地导入。下载 URL、列表服务、镜像及网络运营方可能记录相关连接信息。列表镜像不代理实际测速；列表更新客户端与下载测速客户端不同，不将下载的禁止代理/重定向约束泛化到列表请求。

测速使用 Android 默认网络，不强制选择蜂窝网络。结果反映当前路由；直连优选前关闭 VPN/代理。应用内测速连接不使用显式 HTTP 代理、不跟随重定向；NO_PROXY 不能绕过系统 VPN/TUN 或透明代理，TLS/实际 Peer 核验也不证明直连。识别 VPN 时会提示，但未识别不等于不存在代理，不自动修改系统代理设置。

Android 测速界面只允许 HTTPS，采用系统 CA、主机名/SNI 校验，并核验实际对端 IP/端口；没有忽略 TLS 错误开关。下载端口设置会覆盖 URL 中的端口。HTTP 测试夹具不代表 Android 产品支持明文测速。

## 流量和结果含义

下载预算限制应用消费的响应体字节，**不是运营商账单或线上总字节硬上限**。协议开销、连接建立、预取和在途数据会额外消耗流量。移动网络先关闭下载或降低预算。

TCP 失败率不等于 ICMP 丢包；吞吐包含连接/TLS 等耗时，不是链路峰值。停止、网络丢失和超时可能产生部分记录；失败、取消和不满足质量要求的下载不应被视为完整推荐。

测速仅在前台运行，离开应用会停止；不提供后台持续运行保证。

仅 TCP 模式按归属运行的最大延迟阈值判定优选（0 不限），不把未下载结果当吞吐测量；未知配置不升级为 TCP 优选。存在下载测量时始终按下载质量判断，失败/取消不会因 TCP 成功而升级。TCP 超时是上限，快速成功或失败可以很快结束，不人为增加等待。

每轮确认启动时自动采样，内部使用本地非密码学随机参数并保存在运行配置用于排障；不是安全随机或匿名化机制，不提供固定模式或参数输入。旧设置/备份仍可兼容读取，但不控制新运行采样策略，已有历史参数不改写。
