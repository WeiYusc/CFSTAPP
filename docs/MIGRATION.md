# 安装、备份与迁移

## 先区分两种导出

- **CSV 导出**：便于查看和处理测速结果，不是应用状态备份。
- **全状态导出**：用于设置、来源、选择、历史和运行记录的备份/恢复。卸载前请使用此项，并在应用之外保留文件。

备份可能含有自定义 URL、IP、测速结果和历史信息，应视为私人数据，不要随意公开。

## 从同包名 Debug 测试版迁移

正式版与 Debug 版签名不同，Android 会拒绝直接覆盖安装。不要通过清除数据、强制卸载或更换密钥尝试“修复”覆盖失败。

1. 在旧版导出全状态到系统文档目录，确认文件已保存在应用之外；建议另存一份。
2. 确认备份可访问后，由你自行决定卸载旧 Debug 版。**卸载会删除应用私有数据。**
3. 安装本仓库正式签名 APK，核对版本与签名信息。
4. 使用全状态恢复入口选择备份，查看预览并显式确认。**恢复替换当前状态，不是合并；操作前也请备份当前数据。**
5. 检查设置、IP 来源、历史记录，并执行一次小预算测速；确认后再清理旧备份。

应用校验恢复文件，失败时请保留原文件和错误信息，不要反复覆盖唯一备份。损坏状态有专门恢复入口；不承诺任意外部 JSON 或其他应用版本格式都兼容。

## 后续正式版升级

本维护分支使用同一长期签名和递增 versionCode 才能原位升级。升级前仍建议备份。其他作者或自行编译的 APK 不因名称相同就具备签名兼容性。

本分支包名为 `com.cfst.app.local`。不同包名可由 Android 分别安装，但数据不会自动共享；不要承诺能自动从原作者应用迁移数据。

## 网络与测试建议

首次验证建议 Wi-Fi、小候选数、低下载预算；再根据需要切换蜂窝网络。离开应用会停止测速。可保留部分结果，不要把取消/失败或短样本当成完整推荐。
