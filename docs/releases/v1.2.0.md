# CFSTAPP 独立维护版 1.2.0

> 本地发布说明草稿；只有上传到正式 Release 后才代表已发布。

Android 7.0+；包名 `com.cfst.app.local`；versionCode `112`。

## 本版变化

- 有界 IPv4/IPv6 候选采样、固定 seed、可配置 TCP 初筛并发和整轮时限；下载保持串行。
- 持久化历史、原始运行记录、全状态导出/恢复与损坏状态恢复。
- 历史单 IP 复测及来源关系，修复压缩/大写 IPv6 literal 的复测保存问题。
- 加强 UUID、来源图和恢复数据校验；保存失败时明确提示。
- 更新测速、来源、历史及设置交互，明确草稿、停止、失败与部分结果。

## 安装提醒

**旧 Debug 测试版不能直接覆盖升级。先导出全状态并在应用外备份，再自行确认卸载、安装和恢复。CSV 不能代替全状态备份。** 以后本维护分支的升级需同一签名和更大 versionCode。

测速会消耗流量。下载预算不是运营商计费流量硬上限；测试遵循 Android 默认网络，前台运行，不保证与桌面版结果一致。
