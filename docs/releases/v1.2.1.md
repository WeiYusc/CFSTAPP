# CFSTAPP 独立维护版 1.2.1（113）本地候选

历史本地候选，尚未发布；下列功能描述仅对应113版本。当前候选见 [1.2.2](v1.2.2.md)，已移除用户固定采样参数。本候选必须重新实机验收，不能沿用112版本的设备反馈。

- 采样算法 v2 消除 /24 网段与主机尾号的低位相关，保留有界分层及 literal/小段优先。
- 默认每轮探索，实际 seed 冻结在运行记录；固定模式可复现同版本候选。旧固定 seed 保留并显示独立、可确认的迁移提示；算法更新不保证重建旧候选。
- TCP-only 优选使用该次运行的延迟阈值；已有下载始终按下载质量判断，失败/取消不升级。
- 当前路由、VPN/代理提示不承诺直连或绕过 VPN/TUN。快速连接可以很快完成，不人为增加等待。

包名 `com.cfst.app.local`。升级需同长期签名；旧 Debug 签名不能覆盖，先导出全状态。降级前保留旧版独立备份，不保证旧 APK 安全读取新设置。

候选 APK 的哈希、签名、真实测试结果以对应交付清单为准；本文不预报未完成的门禁。仪器测试编译不等于设备执行。分发须同时提供准确源码、GPL、第三方许可及对应 PSL 源数据，不能仅转发裸 APK。
