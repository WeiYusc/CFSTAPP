# CFSTAPP · 独立维护增强版

基于 [Hsia97/CFSTAPP](https://github.com/Hsia97/CFSTAPP) 的 Android Cloudflare IP 测速应用，由 WeiYusc 独立维护；不是上游官方发行版，也不是 Cloudflare 官方产品。原项目参考 [XIU2/CloudflareSpeedTest](https://github.com/XIU2/CloudflareSpeedTest)，本分支保留原有来源和 GPL-3.0 许可证。

当前本地候选：**1.2.1（113，尚未发布/实机复验）** · Android **7.0 / API 24 及以上** · 包名 `com.cfst.app.local`。

## 主要能力

- IPv4 / IPv6 literal 和 CIDR 输入、列表更新、来源与网段选择；非法输入不静默部分导入。
- 标准测速：有界候选生成、默认每轮探索 seed（可切回固定复现）、可配置 TCP 初筛并发、串行下载，以及整轮总时限（默认 120 秒，可设 30–600 秒）。运行记录冻结实际 seed；时限包含准备和网络测量，收尾持久化可能继续进行，不保证界面精确到秒释放。
- 保存结果和原始运行记录，区分成功、失败、停止与部分结果；历史结果可发起单 IP 复测，并保留来源关系。
- 参数草稿与显式保存、CSV 导出、全状态备份与显式恢复；检测损坏状态并提供恢复入口。
- HTTPS、系统 CA 和主机名校验；应用层指定候选 IP，核验实际对端，禁止 HTTP 重定向及显式 HTTP 代理；不承诺绕过系统 VPN/TUN 或透明代理。

## 使用前须知

1. **下载测速会消耗网络流量。** 预算约束应用消费的响应体字节，不是运营商计费流量上限；TLS、HTTP、TCP 开销、预取及在途数据会额外消耗流量。移动网络建议先关闭下载或降低预算。
2. 使用 Android 默认网络。结果反映当前路由，直连优选前关闭 VPN/代理；未检测到 VPN 不代表没有代理。要测蜂窝网络请自行关闭 Wi-Fi；不强制绑定蜂窝网络。
3. 测速仅在前台运行，离开应用会停止，不提供后台常驻测速保证。
4. TCP 探测失败率不是 ICMP 丢包率；吞吐包含连接/TLS 等耗时，不保证与桌面版 CloudflareSpeedTest 数值一致。
5. IPv6 大前缀不凭空生成“可用节点”；**内置/官方 IPv6 大前缀列表不能直接生成候选**，请导入实际 literal 或最多 256 成员的小段。固定来源与 seed 仅在相同采样算法版本重现候选，不保证重现网络结果；1.2.1 算法 v2 不重建旧版本 seed 的候选。当前没有 fast 模式，快捷预设只是参数草稿。
6. CSV 是结果导出，**不能代替全状态备份**。卸载或更换签名前请先导出全状态并在应用外保留。

## 安装和升级

仅从本仓库 Releases 获取本维护分支的**完整发行包（APK、许可声明与对应源码）**，不要仅转发裸 APK。核对随版本发布的 SHA-256 和签名指纹。首次安装需要允许安装未知来源应用。

本分支使用独立长期签名。**同包名的旧 Debug 测试版无法直接覆盖安装**，必须先备份，再由用户确认卸载、安装和恢复。原作者版本和本维护分支也不承诺签名兼容。详细步骤见 [迁移说明](docs/MIGRATION.md)。

## 开发与反馈

构建需要 JDK 17 和 Android SDK 34，使用仓库自带 Gradle Wrapper。Debug 构建仅供开发；Release 默认不携带签名凭据，参见 [构建文档](docs/BUILDING.md)。

问题反馈请附 Android 版本、应用版本、网络类型、复现步骤和已脱敏的错误信息。请勿上传完整私人备份、凭据或敏感网络记录。
